# TBO – Conteúdo Gráfico

Repositório central de materiais gráficos da TBO.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `logos/` | Logótipos (variantes: cor, branco, preto, ícone) |
| `imagens/` | Fotografias e ilustrações |
| `templates/` | Modelos editáveis (Canva, Figma, PSD, etc.) |
| `redes-sociais/` | Posts, stories, capas e avatares |
| `guia-de-marca/` | Cores, tipografia e regras de utilização |

## Convenções

- Nomes em minúsculas, sem espaços ou acentos, separados por hífen: `tbo-logo-horizontal-cor.svg`
- Incluir a versão quando relevante: `-v2`
- Preferir **SVG** para logótipos e **PNG** (fundo transparente) quando SVG não for possível
- Fotografia em **JPG/WebP**; originais editáveis em `templates/`
- Redes sociais: indicar o formato no nome, ex. `post-1080x1080`, `story-1080x1920`
- Ficheiros muito grandes (>50 MB): usar Git LFS
